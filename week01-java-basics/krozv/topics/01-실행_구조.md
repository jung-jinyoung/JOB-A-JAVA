# 1. 실행 구조

## 학습 목표
- `.java` → `.class` → JVM 로딩 → 실행
- JVM / JRE / JDK 차이
- 클래스 로더가 하는 일 (개념 수준)

### `.java` → `.class` → JVM 로딩 → 실행

1. `.java` 파일 작성
   - 개발자가 소스 코드를 작성한 뒤 `javac` 컴파일러로 `.class` 바이트코드 파일을 생성
   - 컴파일러 : 사람이 작성한 프로그래밍 언어를 컴퓨터가 이해할 수 있는 형태로 바꿔주는 프로그램
```bash
➜  java_self javac HelloWorld.java
➜  java_self ls
HelloWorld.class HelloWorld.java
```
2. 클래스 파일 로딩
   - JVM이 `.class` 파일을 읽어들여 메모리에 적재
   - 이때 클래스 로더가 클래스 경로에서 클래스를 찾고, 바이트코드를 JVM 내부 구조로 변환

```bash
➜  java -verbose:class HelloWorld
[0.089s][info][class,load] HelloWorld source: file:/Users/parkjuyeon/java_self/
```

3. 링크(Link)
   - 로드된 클래스에 대해 검증(Verification), 준비(Preparation), 해석(Resolution)을 수행
   - 검증: 바이트코드가 JVM 규칙을 준수하는지 확인
   - 준비: 클래스 변수(static 필드)에 기본값을 할당
   - 해석: 심볼릭 참조를 직접 메모리 주소로 변환

4. 초기화(Initialization)
   - `static` 초기화 블록과 `static` 필드의 값이 설정되는 단계
   - 초기화가 완료되어야 `main()` 메서드를 호출할 수 있음

```java
public class HelloWorld {

    static {
        System.out.println("1. static 초기화");
    }

    public static void main(String[] args) {
        System.out.println("2. main 실행");
    }
}
```

```bash
➜  java_self nano HelloWorld.java
➜  java_self javac HelloWorld.java
➜  java_self java HelloWorld
1. static 초기화
2. main 실행
```

5. 실행(Execution)
   - JVM이 `main(String[] args)`를 찾아 실행
   - `main()` 내에서 생성된 객체는 힙 영역에 저장되고, 스택에는 지역 변수와 호출 정보가 적재

## JVM / JRE / JDK 차이

- JDK(Java Development Kit)
  - 자바 개발에 필요한 도구 모음
  - 컴파일러(`javac`), 디버거, 라이브러리, JRE 등이 포함

- JRE(Java Runtime Environment)
  - 자바 애플리케이션을 실행하기 위한 환경
  - JVM과 표준 라이브러리만 포함하며, 개발 도구는 포함X

- JVM(Java Virtual Machine)
  - 자바 바이트코드를 실행하는 가상 머신
  - 플랫폼 독립성을 제공하며, 메모리 관리와 JIT 컴파일을 담당

## 클래스 로더가 하는 일

- 클래스 로더는 자바 클래스 파일을 JVM 내부로 가져오는 역할을 함
- 클래스 로더 종류
  - Bootstrip ClassLoader: JDK 핵심 라이브러리 로드
  - Platform ClassLoader: 확장 라이브러리 로드
  - Application ClassLoader: 애플리케이션 클래스 경로의 클래스를 로드

```java
public class HelloWorld {
    public static void main(String[] args) {

        ClassLoader loader = HelloWorld.class.getClassLoader();

        System.out.println(loader);
        System.out.println(loader.getParent());
        System.out.println(loader.getParent().getParent());
    }
}
```

```bash
➜  java_self java HelloWorld
jdk.internal.loader.ClassLoaders$AppClassLoader@22d8cfe0
jdk.internal.loader.ClassLoaders$PlatformClassLoader@253ad0a0
null #이게 Bootstrip ClassLoader(일반적인 java 객체로 표현X)
```

## 예시 실행 흐름

```text
1. 개발자가 HelloWorld.java 작성
2. javac HelloWorld.java -> HelloWorld.class 생성
3. java HelloWorld 실행
4. JVM이 클래스를 로드하고 링크, 초기화 수행
5. JVM이 HelloWorld.main() 호출
```

## 핵심 요약

- `.java`는 사람이 읽는 소스 코드, `.class`는 JVM이 실행하는 바이트코드
- JDK는 개발+실행 도구, JRE는 실행 환경, JVM은 실제 실행 엔진
- 클래스 로더는 클래스 파일을 찾아 로드하고, 위임 모델로 안전하게 처리한다

# Comparable과 Comparator

## 1. Comparable과 자연 순서

`Comparable`은 객체 클래스 내부에서 해당 객체의 기본 정렬 순서를 정의하는 인터페이스다.

이 기본 순서를 자연 순서라고 한다. (오름차순, 사전순 ...)

```java
public interface Comparable<T> {
    int compareTo(T other);
}
```

`compareTo()`의 반환값은 다음 의미를 가진다.

```text
음수 → 현재 객체가 other보다 앞
0   → 두 객체의 정렬 우선순위가 같음
양수 → 현재 객체가 other보다 뒤
```

### Integer의 자연 순서

`int`는 원시 타입이므로 `Comparable`을 구현하지 않는다. 객체 타입인 `Integer`가 `Comparable<Integer>`를 구현한다.

OpenJDK의 실제 구현은 다음과 같은 구조다.

```java
public int compareTo(Integer anotherInteger) {
    return compare(this.value, anotherInteger.value);
}
```

내부의 `Integer.compare()`는 두 값을 빼지 않고 직접 비교한다.

```java
public static int compare(int x, int y) {
    return (x < y) ? -1 : ((x == y) ? 0 : 1);
}
```

따라서 `Integer`의 자연 순서는 숫자 오름차순이다.

```java
Integer[] numbers = {20, 10, 30};

Arrays.sort(numbers);
```

결과:

```text
[10, 20, 30]
```

### String의 자연 순서

`String`은 `Comparable<String>`을 구현한다.

`String.compareTo()`는 두 문자열을 왼쪽 문자부터 비교하고 처음으로 다른 문자를 발견하면 그 문자의 순서로결과를 결정한다.

```java
"apple".compareTo("apply");
```

비교 과정:

```text
a와 a → 같음
p와 p → 같음
p와 p → 같음
l과 l → 같음
e와 y → 다름
```

`e`가 `y`보다 앞이므로 `"apple"`이 먼저 정렬된다.

한 문자열이 다른 문자열의 앞부분과 완전히 같다면 짧은 문자열이 앞에 온다.

```java
"java".compareTo("javascript");
```

`"java"`가 더 짧으므로 사전순에서 먼저 정렬된다.

```text
java
javascript
```

### 직접 만든 객체의 자연 순서

직접 만든 클래스는 개발자가 `Comparable`을 구현해 자연 순서를 정할 수 있다.

```java
class Student implements Comparable<Student> {
    private int studentId;
    private String name;

    @Override
    public int compareTo(Student other) {
        return Integer.compare(
            this.studentId,
            other.studentId
        );
    }
}
```

위 코드에서는 `studentId`를 비교하므로 `Student`의 자연 순서는 학번 오름차순이다.

```java
Arrays.sort(students);
```

별도의 비교 기준을 전달하지 않으면 `Student.compareTo()`가 사용된다.

자연 순서는 항상 사전순이라는 뜻이 아니다.

```text
Integer의 자연 순서 → 숫자 오름차순
String의 자연 순서  → 사전순
Student의 자연 순서 → 개발자가 compareTo()에 정의한 순서
```

## 2. Comparator와 외부 정렬 기준

`Comparable`은 클래스 내부에서 대표적인 자연 순서 하나를 정한다.

하지만 같은 객체도 상황에 따라 여러 기준으로 정렬할 수 있다.

```text
학생 학번순
학생 이름순
학생 점수순
학생 나이순
```

이때 클래스 외부에서 별도의 정렬 기준을 정의하는 `Comparator`를 사용한다.

```java
public interface Comparator<T> {
    int compare(T first, T second);
}
```

### Comparable과 Comparator 비교

```text
Comparable
→ 클래스 내부에서 구현
→ compareTo(other) 사용
→ 객체의 대표적인 자연 순서 정의

Comparator
→ 클래스 외부에서 정의
→ compare(first, second) 사용
→ 상황에 따라 여러 정렬 기준 정의
```

예를 들어 `Student`의 자연 순서가 학번순이어도 Comparator를 전달해 점수순으로 정렬할 수 있다.

```java
Comparator<Student> scoreComparator =
    (first, second) -> Integer.compare(
        first.getScore(),
        second.getScore()
    );

Arrays.sort(students, scoreComparator);
```

Comparator를 전달하면 `Student.compareTo()`보다 전달한 Comparator의 기준이 우선한다.

## 3. Comparator.comparing()

Comparator를 람다로 직접 작성할 수 있다.

```java
Comparator<Student> nameComparator =
    (first, second) ->
        first.getName().compareTo(
            second.getName()
        );
```

`Comparator.comparing()`을 사용하면 객체에서 어떤 값을 꺼내 비교할지만 지정할 수 있다.

```java
Comparator<Student> nameComparator =
    Comparator.comparing(
        Student::getName
    );
```

`Student::getName`은 다음 람다와 같은 의미의 메서드 참조다.

```java
student -> student.getName()
```

`getName()`이 반환하는 타입은 `String`이므로 `String`의 자연 순서인 사전순으로 비교한다.

파이썬의 `key`와 비슷한 역할이다.

```python
sorted(students, key=lambda student: student.name)
```

```java
Arrays.sort(
    students,
    Comparator.comparing(Student::getName)
);
```

비교 기준이 `int`라면 `comparingInt()`를 사용할 수 있다.

```java
Comparator.comparingInt(
    Student::getScore
);
```

## 4. thenComparing()

`thenComparing()`은 앞의 비교 기준으로 순서를 결정할 수 없을 때 사용할 다음 기준을 연결한다.

학생을 점수 오름차순으로 정렬하고, 점수가 같으면 이름 사전순으로 정렬하려면 다음과 같이 작성한다.

```java
Comparator<Student> comparator =
    Comparator
        .comparingInt(Student::getScore)
        .thenComparing(Student::getName);
```

동작 순서:

```text
1. 점수를 비교한다.
2. 점수가 다르면 점수순으로 결정한다.
3. 점수가 같으면 이름을 비교한다.
4. 이름 사전순으로 결정한다.
```

여러 기준을 계속 연결할 수도 있다.

```java
Comparator
    .comparing(Student::getDepartment)
    .thenComparingInt(Student::getScore)
    .thenComparing(Student::getName);
```

우선순위:

```text
부서 오름차순
→ 같은 부서라면 점수 오름차순
→ 점수도 같다면 이름 사전순
```

## 5. reversed()

`reversed()`는 앞에서 만든 Comparator의 정렬 방향을 뒤집는다.

```java
Comparator
    .comparing(Student::getName)
    .reversed();
```

이름 사전순의 반대인 이름 역순으로 정렬된다.

```text
철수 → 민수 → 영희
```

`reversed()`의 위치에 주의해야 한다.

```java
Comparator
    .comparing(Student::getDepartment)
    .reversed()
    .thenComparing(Student::getName);
```

정렬 기준:

```text
부서 내림차순
→ 같은 부서라면 이름 오름차순
```

반면 모든 기준을 연결한 뒤 마지막에 `reversed()`를 호출하면 지금까지 만든 전체 Comparator가 뒤집힌다.

```java
Comparator
    .comparing(Student::getDepartment)
    .thenComparing(Student::getName)
    .reversed();
```

정렬 기준:

```text
부서 내림차순
→ 같은 부서라면 이름 내림차순
```

특정 하위 기준만 뒤집고 싶다면 해당 Comparator를 별도로 만들어 전달한다.

```java
Comparator
    .comparing(Student::getDepartment)
    .thenComparing(
        Comparator
            .comparingInt(Student::getScore)
            .reversed()
    );
```

정렬 기준:

```text
부서 오름차순
→ 같은 부서라면 점수 내림차순
```

## 6. 뺄셈 Comparator의 오버플로우

정수를 오름차순으로 비교할 때 다음처럼 뺄셈 결과를 반환하는 코드가 있다.

```java
(a, b) -> a - b
```

작은 값에서는 정상적으로 보인다.

```java
3 - 5 = -2
```

음수가 반환되므로 `3`이 `5`보다 앞에 놓인다.

그러나 두 정수의 차이가 `int` 범위를 벗어나면 오버플로우가 발생한다.

```java
int a = Integer.MAX_VALUE;
int b = -1;
```

수학적인 결과:

```text
2,147,483,647 - (-1)
= 2,147,483,648
```

이 값은 `int`의 최댓값을 초과한다. 실제 `int` 계산 결과는 음수로 바뀐다.

```text
-2,147,483,648
```

Comparator는 음수 결과를 보고 `Integer.MAX_VALUE`를 `-1`보다 앞에 배치해야 한다고 잘못 판단한다.

반대쪽에서도 문제가 발생할 수 있다.

```java
int a = Integer.MIN_VALUE;
int b = 1;

int result = a - b;
```

수학적인 결과는 `int`의 최솟값보다 작기 때문에 오버플로우가 발생하고 양수로 바뀐다.

따라서 다음 방식은 사용하지 않는 것이 좋다.

```java
(a, b) -> a - b
```

## 7. Integer.compare()

정수 비교에는 `Integer.compare()`를 사용한다.

```java
(a, b) -> Integer.compare(a, b)
```

`Integer.compare()`는 두 값을 빼지 않고 대소 관계를 직접 확인한다.

```java
public static int compare(int x, int y) {
    return (x < y) ? -1 : ((x == y) ? 0 : 1);
}
```

중간 계산에서 덧셈이나 뺄셈을 하지 않으므로 오버플로우가 발생하지 않는다.

오름차순:

```java
(a, b) -> Integer.compare(a, b)
```

내림차순:

```java
(a, b) -> Integer.compare(b, a)
```

더 선언적인 방식도 사용할 수 있다.

```java
Comparator.comparingInt(Student::getScore);
```

```java
Comparator
    .comparingInt(Student::getScore)
    .reversed();
```

## 최종 요약

```text
Comparable
→ 클래스 내부의 기본 자연 순서
→ compareTo(other)

Comparator
→ 클래스 외부에서 전달하는 별도 정렬 기준
→ compare(first, second)

Comparator.comparing()
→ 객체에서 비교할 기준값 추출

thenComparing()
→ 앞의 기준이 같을 때 다음 기준 적용

reversed()
→ 만들어진 Comparator의 정렬 방향 반전

(a, b) -> a - b
→ int 오버플로우 위험

Integer.compare(a, b)
→ 뺄셈 없이 비교하므로 안전
```

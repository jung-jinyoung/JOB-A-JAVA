# 4주차 — 재귀 · 그래프 · 스트림

> 오너: A / 마감: 금 23:59 (PR) · 일 23:59 (리뷰·머지)
> **전반부 마지막 주차** — 주말에 전반부 회고를 함께 진행합니다.

## 학습 목표

- 재귀 호출이 메모리에서 어떻게 쌓이는지 안다
- 그래프 탐색 코드를 **재사용 가능한 형태**로 작성할 수 있다
- 스트림이 언제 유리하고 언제 불리한지 판단할 수 있다

## 학습 주제

### 1. 재귀와 콜 스택

- 스택 프레임이 쌓이는 구조, `StackOverflowError`
- 재귀 깊이 한계를 결정하는 것 (스택 크기, `-Xss` 옵션)
- 자바에 꼬리 재귀 최적화가 없다는 것의 의미
- 재귀 → 반복문 변환 (명시적 스택 사용)

### 2. JVM 메모리 구조

- 스택 / 힙 / 메타스페이스
- 지역 변수와 객체는 각각 어디에 저장되는가
- GC 개념 (Minor/Major GC 수준까지만)

### 3. 그래프 표현과 탐색

- 인접 행렬 vs 인접 리스트 — 선택 기준 (밀집/희소)
- DFS(재귀·스택) / BFS(큐) 구현
- 방문 배열, 최단 거리 기록

### 4. 람다와 스트림

- 함수형 인터페이스, 람다가 컴파일되는 방식
- 중간 연산 / 최종 연산, **지연 평가**
- 스트림이 for문보다 느릴 수 있는 경우 (원시타입 박싱, 짧은 컬렉션)
- `Optional` 올바른 사용법 (`get()` 남용 금지)

### 구현 과제 — `Graph` 클래스

**요구사항**

- 인접 리스트 기반, 정점 수를 받아 초기화
- `addEdge(int u, int v)` — 무방향/방향 옵션
- `dfs(int start)` — 방문 순서 반환
- `bfs(int start)` — 방문 순서 반환
- `shortestPath(int start)` — 시작점에서 각 정점까지 최단 거리(간선 가중치 1)
- JUnit 테스트 필수

> 이 클래스는 **5주차 스프링 이식 대상**이 됩니다. 인터페이스와 구현을 깔끔히 분리해두세요.
